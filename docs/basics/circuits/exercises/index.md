# 习题

与 [知识点](../notes/index.md) 逐章对应的练习题，每章 6–10 题，由易到难，按题型分组。标注"作业 x-x"的题目来自课程作业（部分做了改编），其余为同类型的典型题。

!!! tip "怎么用"
    1. 先读对应章节的知识点，再**独立做题**，写出完整过程；
    2. 做完再展开 **答案** 核对结果；
    3. 不对或卡住时展开 **解析**，看思路和易错点，然后合上重做一遍。

    每题都给出了全部数值、参考方向和开关动作时刻；没有特别说明时，正弦量采用与笔记相同的 **sin 约定、有效值相量**：$u=\sqrt2U\sin(\omega t+\psi)\leftrightarrow\dot U=U\angle\psi$。

| 难度 | 含义 |
| --- | --- |
| :material-star::material-star-outline::material-star-outline: | 基本概念、直接套公式 |
| :material-star::material-star::material-star-outline: | 典型题，需要两三步推理 |
| :material-star::material-star::material-star: | 综合题或容易踩坑的题 |
