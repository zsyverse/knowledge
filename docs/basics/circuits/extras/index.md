# 拓展补充

主线笔记覆盖了课程作业涉及的内容；这里补上邱关源《电路》中**超出当前作业范围**、但在后续课程（模拟电子技术、信号与系统、自动控制）里会反复用到的专题。每篇的写法与 [知识点](../notes/index.md) 相同：先给结论，再给带完整解答的例题，最后是附答案和解析的练习；所有数值都用脚本独立验算过。

!!! note "约定不变"
    关联参考方向、sin 约定 + 有效值相量，与主线笔记一致。二端口的端口电流一律**从 + 端流入网络**，T 参数写成 $\dot U_1=A\dot U_2-B\dot I_2$、$\dot I_1=C\dot U_2-D\dot I_2$。

| 专题 | 主要内容 | 练习 |
| --- | --- | --- |
| [含理想运放的电路](opamp.md) | 虚短虚断，七种基本电路，多级运放的节点法，有源 RC 电路 | 5 题 |
| [二端口网络](two-port.md) | Z/Y/H/T 参数与换算，互易与对称，T/Π 等效，连接，带源带载，回转器与负阻抗变换器 | 5 题 |
| [运算法](laplace.md) | 拉氏变换与部分分式，s 域元件模型，运算电路，网络函数与零极点、稳定性 | 5 题 |
| [二阶电路与卷积积分](second-order.md) | 二阶电路的经典解法，RLC 串联与 GCL 并联，卷积积分及图解 | 5 题 |
| [矩阵形式与状态方程](matrix-state.md) | 图、树、割集，A/B/Q 矩阵，节点方程 $\mathbf Y_n\mathbf U_n=\mathbf J_n$，状态方程 | 4 题 |
| [特勒根、互易与对偶](tellegen-duality.md) | 特勒根定理两种形式，两次测量问题，互易定理三种形式，对偶电路 | 4 题 |
| [非线性电阻电路](nonlinear.md) | 静态与动态电阻，负载线，分段线性化，迭代，小信号分析 | 5 题 |
| [均匀传输线（了解）](transmission-line.md) | 电报方程，特性阻抗与传播常数，无损线，反射与匹配 | 3 题 |

!!! tip "建议顺序"
    运放与二端口可以在学完 [电路定理](../notes/circuit-theorems.md) 后直接看；运算法、二阶电路接在 [动态电路](../notes/dynamic-circuits.md) 之后；矩阵形式、特勒根与对偶是对分析方法的"理论化"，非线性与传输线相对独立。
